Features

Everything a start page should do. Nothing it shouldn't.

No framework, no build step, no database, no login screen — one small page that loads instantly and stays out of your way.

One token, every device

Paste your sync token once per device and your favorites, pages, and settings converge everywhere. Leave it blank and the app works fully offline-local.

Private by design

No email, no name, no password. Your token is your whole identity — the server stores only its hash and your one small document. Nobody can see anyone else's data.

Icons that just work

Tiles resolve real product logos first, then favicons, then a colored letter — automatically, through a privacy-preserving proxy. Or paste any icon URL you like.

Pages for every context

Group tiles into pages — work, homelab, mobile — switched with a chip bar or linked directly with ?p=. Each device can open to its own default page.

Local files too

Add file:/// paths — or just paste C:\ and network paths — and get folder tiles beside your sites. A click hands you the path, ready for the address bar.

Bring your bookmarks

Import a browser bookmarks file and folders become pages; import and export the whole document as JSON any time. Merges are deduplicated — nothing gets overwritten.

Make it yours

Dark or light theme, separate desktop and mobile wallpapers, background color, and per-page sorting — alphabetical or drag-anywhere manual order.

Open source

MIT licensed, a single HTML file plus one tiny Worker. Read every line in minutes — or deploy your own copy on Cloudflare's free tier.

How it works

Set up in under a minute

There is nothing to install and no form to fill in. A token takes the place of an entire account system.

Get your token

One click below generates a random token — that token is your identity. Save it in your password manager like the key it is.

Paste it in the app

Open favorites.mykk.us → Settings (⚙) → Sync, paste the token, save. Do the same on your phone, laptop, and work machine.

Add favorites anywhere

Every device now shows the same tiles, pages, and settings — newest change wins. Set it as your browser's new-tab or home page and you're done.

Why a token instead of a login? Because then we never need your email, can't profile you, and have nothing about you to leak. The server keeps a hash of the token and one small JSON document — that's the entire "account".

FAQ

Questions, answered

Is it really free?

Yes. The hosted instance runs comfortably on Cloudflare's free tier, so a limited number of new tokens are issued per day to keep it that way. If today's are gone, come back tomorrow — or self-host in ten minutes.

What do you store about me?

A SHA-256 hash of your token and one JSON document (your favorites and settings), capped at 100 KB. No email, no name, no IP logs tied to your data, no cookies. Analytics is a self-hosted, cookieless Plausible instance that counts page views, not people.

What if I lose my token?

It can't be recovered or reset — there's no identity on file to verify you with. Keep it in a password manager, and use Settings → Data → Export for occasional backups. With a backup, a fresh token plus one import puts everything back.

How do local file:// tiles work?

Add any file:/// URL — or paste a plain C:\, network, or Unix path and it's converted for you. Browsers don't let a web page open file:// links directly, so clicking a file tile copies the location for pasting into the address bar (with a local-links browser extension installed, the click opens it directly).

Can I use it without syncing?

Yes — without a token the app is fully functional and keeps everything in your browser's local storage. Add a token later and your local favorites sync up as-is.

Can I run my own?

Absolutely. It's MIT licensed: one Worker, one KV namespace, no build step. wrangler deploy and you're live on your own domain — the README walks through it.
